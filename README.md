# 조기축구 회원증 메이커

조기축구회 회원증을 만들어 **A4 한 장에 10장씩** 인쇄하는 도구입니다.
엑셀 명단을 붙여넣고 증명사진만 넣으면 앞면·뒷면 인쇄 파일이 바로 나옵니다.

**👉 [바로 쓰기](https://simhyeoncheol.github.io/soccer-id-card/)**

<br>

## 서버가 없습니다

회원 이름·생년월일·얼굴 사진은 **브라우저 밖으로 한 번도 나가지 않습니다.**
모든 처리가 보고 있는 그 페이지 안에서 끝나고, 데이터는 브라우저의
IndexedDB 에만 저장됩니다. 업로드하는 곳도, 수집하는 주체도 없습니다.

대신 브라우저를 바꾸거나 방문 기록을 지우면 사라집니다.
명단을 다 채우면 **백업 파일 저장**을 한 번 눌러 두세요.

<br>

## 기본 서식

**어울림축구연합회 / 동남FC** 서식이 기본으로 들어가 있습니다.
띠 문구, 발급 기관, 직인 글자, 카페 주소, 엠블럼, 뒷면 문구가 미리 채워져 있어
회원 명단만 넣으면 바로 인쇄할 수 있습니다.

다른 조기회라면 **② 우리 조기회 정보**의 칸을 그대로 덮어쓰면 됩니다.
되돌리고 싶으면 같은 칸 아래 **어울림 서식으로 되돌리기** 를 누르세요.
회원 명단은 건드리지 않습니다.

<br>

## 쓰는 순서

1. **카드 디자인** — 정통 / 모던 / 크레스트 중에 고릅니다.
2. **조기회 정보** — 이름, 테마 색, 발급 기관, 직인 글자, 창단 연도.
   이미지는 셋을 따로 넣습니다 — **배경 엠블럼**(카드 뒤 워터마크),
   **발급기관 로고**(발급 기관 글자 왼쪽), **직인**(도장 사진).
   직인 이미지를 비우면 직인 글자를 정사각 격자로 앉혀 만듭니다.
   배경 엠블럼을 비우면 조기회 이름과 창단 연도로 원형 도장 문양을 씁니다.
3. **뒷면 유의사항** — 한 줄에 한 항목. 한 항목이 두 줄을 넘지 않도록
   글자 크기가 자동으로 줄어듭니다.
4. **회원 명단** — 엑셀에서 셀 범위를 복사해 그대로 붙여넣습니다.
5. **인쇄** — 앞면 페이지, 뒷면 페이지가 차례로 나옵니다.

### 명단 붙여넣기

첫 줄이 `이름 / 등번호 / 생년월일 / 소속팀` 머리글이면 순서를 알아서 맞추고,
머리글이 없으면 왼쪽부터 그 순서로 읽습니다. 탭 구분(엑셀 복사)과 CSV 둘 다 됩니다.

생년월일은 `1967-11-14`, `67.11.14`, `671114` 를 모두 인식해 `67.11.14` 로 통일하고,
회원번호 `팀명-67-11-14` 를 자동으로 만듭니다.

<br>

## 인쇄 설정

**크롬을 쓰세요.** 배율과 여백을 가장 정확하게 다룹니다.
사파리는 여백 옵션이 달라 카드가 몇 mm 틀어질 수 있습니다.

인쇄 창에서 셋 다 맞춰야 카드가 규격대로 나옵니다.

- 배율 **100% (실제 크기)** — "용지에 맞춤"이 아닙니다
- 여백 **없음**
- **배경 그래픽** 켜기 — 안 켜면 색 띠가 통째로 사라집니다

먼저 한 장만 뽑아 자에 대보고, 86 × 54 mm 가 맞으면 나머지를 뽑으세요.

### 만드는 순서

1. 앞면 인쇄 (120g 이상 용지 권장)
2. 같은 종이를 뒤집어 뒷면 인쇄 — 뒷면 페이지는 좌우가 미리 뒤집혀 있어 그대로 넣으면 맞습니다
3. 재단선대로 컷팅, 모서리는 5mm 라운드 펀치
4. 카드용 라미네이팅 파우치(60 × 90 mm)에 코팅, 투명 테두리 2~3mm 남기고 재단
5. 목걸이 구멍 펀칭

<br>

## 규격

| 항목 | 값 |
| --- | --- |
| 카드 | 86 × 54 mm (CR80, 신용카드 규격) |
| 배치 | A4 2열 × 5행 = 10장 |
| 카드 간격 | 가로 4mm / 세로 2.4mm |
| 증명사진 | 3:4, 264 × 348 px 로 자동 크롭 |

## 직접 띄우기

빌드 도구가 없습니다. 정적 파일 그대로 올리면 끝입니다.

```bash
git clone https://github.com/simhyeoncheol/soccer-id-card.git
cd soccer-id-card
python3 -m http.server 8000   # http://localhost:8000
```

`file://` 로 열어도 대부분 동작하지만, IndexedDB 가 막히는 브라우저가 있어
로컬 서버로 여는 편이 안전합니다.

<br>

## 구성

```
index.html            전부 여기에 (HTML + CSS + JS, 의존성 없음)
assets/fonts.css      @font-face 선언
assets/fonts/*.woff2  자체 호스팅 웹폰트 488개 / 4.6MB
assets/logo-dongnam.png  동남FC 엠블럼 (배경 워터마크)
assets/logo-oullim.png   어울림축구연합회 배지 (발급기관 로고)
assets/seal-oullim.png   어울림연합회장인 직인
```

외부 CDN을 하나도 쓰지 않아서, 폰트 CDN이 막힌 사내망이나 학교망에서도
글자가 깨지지 않습니다.
