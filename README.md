# 조기축구 회원증 메이커

조기축구회 회원증을 만들어 **A4 한 장에 10장씩** 인쇄하는 도구입니다.
엑셀 명단을 붙여넣고 증명사진만 넣으면 앞면·뒷면 인쇄 파일이 바로 나옵니다.

**👉 [바로 쓰기](https://simhyeoncheol.github.io/soccer-id-card/)**

<br>

## 저장 — Firebase 클라우드

관리자 아이디로 로그인해야 쓸 수 있고, 명단은 **Firebase Firestore**에 자동 저장됩니다.
다른 컴퓨터·브라우저에서 로그인해도 같은 명단이 이어지고, 관리자 여럿이 동시에 고치면
서로의 화면에 바로 반영됩니다. 로그아웃하면 그 브라우저에 남은 임시 사본도 지웁니다.

| 문서 | 내용 |
| --- | --- |
| `members/{key}` | 회원 한 명 (이름·등번호·생년월일·소속팀·사진·순서) |
| `idcard/settings` | 조기회 정보 + 뒷면 문구 |
| `idcard/img_logo` · `img_issuerLogo` · `img_sealImg` | 이미지 세 칸 |

증명사진은 264×348 JPEG(30KB 안팎)라 Firestore 문서에 그대로 넣습니다.
Cloud Storage 를 쓰지 않으니 무료(Spark) 요금제로 충분합니다.

### 처음 한 번 설정

1. [Firebase 콘솔](https://console.firebase.google.com)에서 프로젝트를 만듭니다.
2. **빌드 → Authentication → 시작하기 → 이메일/비밀번호** 를 켭니다.
3. **Authentication → 설정 → 사용자 작업** 에서 **생성(가입) 사용** 을 끕니다.
   콘솔에서 만든 계정 말고는 아무도 가입하지 못하게 막는 설정입니다. 꼭 끄세요.
4. **Authentication → 사용자 → 사용자 추가** 로 관리자 계정을 만듭니다.
   이메일 칸에 `아이디@soccer-idcard.example` 을 넣으면, 로그인 화면에서는 `아이디` 만 치면 됩니다.
   아이디는 영문 소문자·숫자·`. _ -`, 비밀번호는 6자 이상(Firebase 규칙)입니다.
5. **빌드 → Firestore Database → 데이터베이스 만들기** (위치 `asia-northeast3` 서울 권장, 프로덕션 모드).
6. **Firestore → 규칙** 탭에 [`firestore.rules`](firestore.rules) 내용을 붙여넣고 게시합니다.
7. **프로젝트 설정 → 일반 → 내 앱 → 웹 앱 추가(</>)** 후 나오는 `firebaseConfig` 값을
   [`firebase-config.js`](firebase-config.js) 에 붙여넣습니다. 이 값은 공개돼도 되는 주소 정보입니다.

예전 버전에서 이 브라우저에 저장해 둔 명단이 있으면, 처음 로그인할 때 클라우드로 올릴지 묻습니다.

<br>

## 기본 서식

**어울림축구연합회 / 동남FC** 서식이 기본으로 들어가 있습니다.
띠 문구, 발급 기관, 직인 글자, 카페 주소, 엠블럼, 뒷면 문구가 미리 채워져 있어
회원 명단만 넣으면 바로 인쇄할 수 있습니다.

다른 조기회라면 **② 우리 조기회 정보**의 칸을 그대로 덮어쓰면 됩니다.
되돌리고 싶으면 같은 칸 아래 **어울림 서식으로 되돌리기** 를 누르세요.
회원 명단은 건드리지 않습니다.

<br>

## 쓰는 순서

1. **카드 디자인** — 정통 / 모던 / 크레스트 중에 고릅니다.
2. **조기회 정보** — 이름, 테마 색, 발급 기관, 직인 글자, 창단 연도.
   이미지는 셋을 따로 넣습니다 — **배경 엠블럼**(카드 뒤 워터마크),
   **발급기관 로고**(발급 기관 글자 왼쪽), **직인**(도장 사진).
   어울림 배지와 직인은 벡터로 그려져 있어 크게 뽑아도 뭉개지지 않습니다.
   직인 이미지를 비우면 직인 글자를 정사각 격자로 앉혀 도장을 만듭니다.
   글자는 Black Han Sans 로 찍어 전각 도장에 가깝게 나옵니다.
   발급 기관 줄은 소속팀 바로 아래에 놓이고, 직인은 그 줄 끝에 붙습니다.
   배경 엠블럼을 비우면 조기회 이름과 창단 연도로 원형 도장 문양을 씁니다.
3. **뒷면 유의사항** — 한 줄에 한 항목. 카드에서도 한 항목이 한 줄에
   들어가도록 글자 크기가 자동으로 줄어듭니다(최소 1.7mm).
4. **회원 명단** — 엑셀에서 셀 범위를 복사해 그대로 붙여넣습니다.
   반대로 **엑셀 내보내기** 를 누르면 명단이 `.xlsx` 파일로 떨어집니다.
5. **인쇄** — 앞면 페이지, 뒷면 페이지가 차례로 나옵니다.

### 명단 붙여넣기

첫 줄이 `이름 / 등번호 / 생년월일 / 소속팀` 머리글이면 순서를 알아서 맞추고,
머리글이 없으면 왼쪽부터 그 순서로 읽습니다. 탭 구분(엑셀 복사)과 CSV 둘 다 됩니다.

생년월일은 `1967-11-14`, `67.11.14`, `671114` 를 모두 인식해 `67.11.14` 로 통일하고,
회원번호 `팀명-67-11-14` 를 자동으로 만듭니다.

### 엑셀 내보내기

**엑셀 내보내기** 는 증명사진·이름·등번호·생년월일·소속팀·회원번호를 `.xlsx` 한 장으로 내려받습니다.
증명사진은 A열 칸을 꽉 채우도록 들어가고(96px), 줄 높이와 열 너비가 거기에 맞춰집니다.
머리글 줄은 카드 테마 색을 배경으로 굵게 찍고, 모든 칸은 가운데 정렬입니다.
나머지 칸은 모두 문자열이라 등번호 `07` 이 `7` 로, 생년월일 `67.11.14` 가 날짜로 바뀌지 않습니다.
머리글이 붙어 있어 이름부터 오른쪽 칸들은 그대로 복사해 다시 붙여넣을 수 있습니다.

명단을 통째로 다른 브라우저로 옮기려면 엑셀 말고 **백업 파일 저장** 을 쓰세요.
조기회 정보와 뒷면 문구까지 함께 담깁니다.

## 인쇄 설정

**크롬을 쓰세요.** 배율과 여백을 가장 정확하게 다룹니다.
사파리는 여백 옵션이 달라 카드가 몇 mm 틀어질 수 있습니다.

인쇄 창에서 셋 다 맞춰야 카드가 규격대로 나옵니다.

- 배율 **100% (실제 크기)** — "용지에 맞춤"이 아닙니다
- 여백 **없음**
- **배경 그래픽** 켜기 — 안 켜면 색 띠가 통째로 사라집니다

먼저 한 장만 뽑아 자에 대보고, 86 × 54 mm 가 맞으면 나머지를 뽑으세요.

### 만드는 순서

1. 앞면 인쇄 (120g 이상 용지 권장)
2. 같은 종이를 뒤집어 뒷면 인쇄 — 뒷면 페이지는 좌우가 미리 뒤집혀 있어 그대로 넣으면 맞습니다
3. 재단선대로 컷팅, 모서리는 5mm 라운드 펀치
4. 카드용 라미네이팅 파우치(60 × 90 mm)에 코팅, 투명 테두리 2~3mm 남기고 재단
5. 목걸이 구멍 펀칭

<br>

## 규격

| 항목 | 값 |
| --- | --- |
| 카드 | 86 × 54 mm (CR80, 신용카드 규격) |
| 배치 | A4 2열 × 5행 = 10장 |
| 카드 간격 | 가로 4mm / 세로 2.4mm |
| 증명사진 | 3:4, 264 × 348 px 로 자동 크롭 |

## 직접 띄우기

빌드 도구가 없습니다. 정적 파일 그대로 올리면 끝입니다.

```bash
git clone https://github.com/simhyeoncheol/soccer-id-card.git
cd soccer-id-card
python3 -m http.server 8000   # http://localhost:8000
```

`file://` 로는 열리지 않습니다(모듈 스크립트). 로컬 서버로 여세요.

에뮬레이터로 시험하려면 `firebase emulators:start --only auth,firestore` 를 띄우고
`http://localhost:8000/?emulator` 로 엽니다. Firestore 포트가 8080 이 아니면 `?emulator=8085` 처럼 적습니다.

<br>

## 구성

```
index.html            전부 여기에 (HTML + CSS + JS)
firebase-config.js    Firebase 프로젝트 설정값
firestore.rules       Firestore 보안 규칙 (콘솔에 붙여넣기)
assets/fonts.css      @font-face 선언
assets/fonts/*.woff2  자체 호스팅 웹폰트 576개 / 4.8MB
assets/logo-dongnam.png  동남FC 엠블럼 (배경 워터마크)
assets/seal-oullim.png   어울림연합회장인 직인 (전서체 사각 양각)
assets/logo-oullim.png   어울림축구연합 배지 (발급기관 로고)
```

폰트는 자체 호스팅이라 폰트 CDN이 막힌 망에서도 글자가 깨지지 않습니다.
Firebase SDK 는 `www.gstatic.com` 에서 불러옵니다.
